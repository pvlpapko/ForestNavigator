# ForestNavigator / Лес Навигатор

Android-приложение для автономной навигации в лесу: GNSS/GPS, компас, точки, треки, навигация к сохранённым местам и заранее скачанные карты.

## Карты

Встроенные режимы разделены явно:

- **Карта** — Open Streets, обычная Open Basemap карта без слоя рельефа.
- **Спутник** — ArcGIS World Imagery.
- **Рельеф** — Open Streets Relief: отдельный Open Basemap relief-стиль + hillshade.
- **Спутник+рельеф** — imagery + hillshade + подписи.
- **Своя карта** — пользовательский MapLibre style URL.

Онлайн и офлайн-режимы используют один и тот же смысл слоёв. Обычная карта больше не строится из старого raster World Street Map, где рельеф был частью самой картинки.

## Офлайн-карты v4

Новая офлайн-система хранится отдельно от старых версий. В 1.5.1 обычная карта и рельеф переведены на Open Streets / Open Streets Relief.

- обычная Open Streets карта скачивается как ArcGIS vector tile package (`.vtpk`);
- спутник и hillshade — как raster tile packages (`.tpkx`);
- каждый слой хранится с явной ролью и форматом;
- незавершённые загрузки живут только во временной папке;
- готовая область становится видимой приложению только после создания финального манифеста;
- старые хранилища `arcgis_offline_v2` и `offline_maps_v3` при обновлении очищаются и не смешиваются с новой системой;
- при пересечении скачанных областей для текущей GPS-позиции выбирается одна готовая область, а не накладывается набор старых карт друг на друга.

После обновления до 1.5.1 старые скачанные области нужно скачать заново. Сохранённые точки, машина, грибные места и треки не удаляются.

## Скорость загрузки

Офлайн-загрузка выполняется параллельно:

- до 6 пакетов одной области одновременно;
- до 8 ArcGIS export jobs суммарно;
- до 2 областей одновременно;
- большие области автоматически делятся на части;
- завершённые части повторно не скачиваются при продолжении;
- пауза и удаление отменяют все активные server-side export jobs.

## GPS и компас

- GNSS: `LocationManager.GPS_PROVIDER`;
- отображаемая позиция фильтруется от кратковременных плохих скачков;
- режим точной точки использует исходные GNSS-фиксы, а не сглаженную координату;
- ArcGIS получает тот же GPS-поток, который использует интерфейс;
- компас сглажен и ограничивает одиночные резкие скачки;
- GPS, компас, точки и навигация продолжают работать без интернета.

## Треки и точки

- точка машины;
- грибные места;
- произвольные точки по GPS или долгому нажатию на карту;
- навигация к точке с направлением и расстоянием;
- запись маршрута через foreground location service;
- локальная SQLite-база.

## Сеть

Онлайн-режим включается только когда Android подтверждает валидированный доступ в интернет. При его потере встроенная карта переключается на скачанную область; наличие мобильной сети без реального интернета не считается онлайн-соединением.
