# ForestNavigator / Лес Навигатор

Android-приложение для автономной навигации в лесу: GNSS/GPS, компас, точки, треки, навигация к сохранённым местам и заранее скачанные карты.

## Карты 1.6.1

В приложении оставлены только два встроенных режима:

- **Карта** — ArcGIS Open Basemap `open/osm-style`.
- **Спутник** — ArcGIS Open Basemap `open/hybrid`: спутниковые снимки с дорогами, границами, объектами и подписями.

Режимы **Рельеф** и **Спутник+рельеф** удалены. Встроенные карты теперь работают через один MapLibre-движок как онлайн, так и офлайн. В 1.6.1 MapLibre получает простой локальный raster-style, а сами 512×512 тайлы идут напрямую из ArcGIS Static Basemap Tiles — без удалённого style JSON, который давал чёрный экран на части устройств.

## Быстрые офлайн-карты

В 1.6.1 прежняя система ArcGIS ExportTileCache/ExportVectorTiles полностью удалена. MapLibre скачивает ресурсы выбранного стиля напрямую в свою offline database.

- снят стандартный MapLibre-лимит 6000 offline tiles;
- клиентский OkHttp-пул увеличен до 64 одновременных запросов, до 32 на один host;
- автоматическая упаковка offline database отключена во время загрузки и выполняется после завершения;
- нет промежуточной сборки TPKX/VTPK на сервере;
- нет рекурсивного деления области на export-пакеты;
- прогресс берётся непосредственно из MapLibre без постоянного обхода файлов;
- поддержаны пауза, продолжение, удаление и несколько активных областей;
- загрузка работает через data-sync foreground service с системным уведомлением;
- радиусы: 2, 5, 10, 25, 50 и 100 км.

Фактическая скорость ограничивается сетью, устройством и сервером поставщика, но приложение не вводит собственный лимит пропускной способности.

## GPS и навигация

- GNSS: `LocationManager.GPS_PROVIDER`;
- сглаженная позиция для отображения карты;
- raw GNSS fixes для режима точного сохранения точки;
- компас и плавное направление карты;
- ручное перемещение карты отключает follow mode до нажатия «Я здесь»;
- точка машины, грибные места и другие тематические точки;
- долгий тап по карте для сохранения произвольной точки;
- навигация к точке с направлением и расстоянием;
- запись маршрута в foreground location service;
- локальная SQLite-база.

Смена картографического движка не удаляет сохранённые точки и треки.
