# ForestNavigator / Лес Навигатор

Android-приложение для автономной навигации в лесу: GPS/GNSS, компас, точки, треки, навигация к сохранённым местам и заранее скачанные карты.

## Карты 1.7.0

Оставлены два режима:

- **Карта** — ArcGIS Open Basemap `open/osm-style`.
- **Спутник** — полноценный **Open Hybrid**: World Imagery как спутниковая подложка + `open/hybrid/detail` как слой дорог, границ, объектов и подписей.

Режимы рельефа удалены.

## Отображение

MapLibre больше не загружает удалённый Esri style JSON напрямую. Приложение само строит простой локальный raster-style:

- карта: один источник Open OSM Style;
- спутник: World Imagery + прозрачный Hybrid Detail поверх.

Это устраняет ситуацию, когда `hybrid/detail` отображался без спутниковой подложки как тёмная дорожная карта.

Начальный масштаб после GPS-фикса — около 200 м. Кнопка «Я здесь» возвращает тот же режим слежения.

## Офлайн-загрузка

В 1.7.0 MapLibre `OfflineManager` полностью исключён из процесса скачивания. Это сделано из-за повторяемых падений при старте загрузки и после pause/delete/restart на отдельных устройствах.

Теперь:

- тайлы скачиваются напрямую через OkHttp;
- до 32 параллельных загрузок на одну область;
- общий HTTP-пул до 64 запросов, до 32 на host;
- каждый регион хранится в отдельной директории;
- пауза просто отменяет coroutine-job;
- продолжение повторно использует уже сохранённые тайлы;
- удаление удаляет только директорию выбранной области;
- отсутствует нативная offline database MapLibre, поэтому нет конфликтов после удаления и повторного запуска;
- прогресс считается по реальным тайлам и байтам;
- приложение не вводит лимит скорости.

Фактическая скорость всё равно зависит от сети, телефона и ограничений серверов поставщика.

## Пользовательские данные

Точки, машина, грибные места и треки хранятся отдельно в SQLite и не удаляются при смене офлайн-карт.
